# 🔌 12V to 5V DC Power Supply Converter PCB

## 📌 Project Overview

This project is a **12V to 5V DC power supply converter** designed using **EasyEDA**. It uses a 7805 voltage regulator to convert a 12V DC input into a regulated 5V DC output for low-power electronic circuits.

This is **Day 1 of my 30-Day PCB Design Challenge**, where I am improving my PCB design skills through practical electronics projects.

## ⚙️ Features

- 12V DC input supply
- Regulated 5V DC output
- 7805 voltage regulator
- Input and output filtering capacitors
- LED power indicator
- Compact PCB layout
- 2D PCB layout and 3D visualization

## 🛠️ Components Used

- 7805 Voltage Regulator (TO-220)
- DC Barrel Jack
- 100µF Input Capacitor
- 10µF Output Capacitor
- LED Indicator
- 460Ω Resistor
- 2-Pin Output Connector

## 💻 Software Used

- **EasyEDA** – Schematic design, PCB layout, routing, and 3D visualization.

## 🔄 Working Principle

1. A 12V DC supply is connected through the input barrel jack.
2. The input capacitor helps reduce input voltage fluctuations.
3. The 7805 regulator converts the input voltage to a nominal 5V output.
4. The output capacitor helps stabilize the regulated supply.
5. An LED acts as a visual power indicator.
6. The regulated 5V output is available through the output connector.
